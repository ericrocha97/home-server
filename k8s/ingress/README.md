# Ingress

Kubernetes workloads use Ingress resources in this directory.

Routes for host-native Docker Compose services are not represented by Kubernetes
Services, EndpointSlices or ExternalName objects. They are generated by Ansible
inside the bundled Traefik HelmChartConfig file provider and point directly to the
host LAN IP and published service port.

Regra de fronteira: `jenkins`, `n8n` e `metabase` **não têm** `Service`/`EndpointSlice`/`ExternalName` — roteamento exclusivo via file provider (`homeServer`/`homeServer-transport` + 3 backends `jenkins`/`n8n`/`metabase` em `k8s-platform`). Qualquer Service/EndpointSlice para esses hostnames seria desvio de fronteira e deve ser rejeitado em review.
